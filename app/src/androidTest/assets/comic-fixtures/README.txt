Synthetic comic fixtures generated by tools/verification/generate_comic_fixtures.py (AGPL-3.0-only).
Two original 2x2 solid-colour PNG pages are deliberately stored as page10 then page2 to verify natural ordering.
RAR4/RAR5 stored archives are generated directly from their public file-format specifications; no UnRAR tool or library is used. 7z compression uses host libarchive only when regenerating fixtures.
Unsafe-path, duplicate-entry and symlink fixtures are deliberately invalid for the reader. No user data or copyrighted comic pages are included.

rar4-compressed.cbr and rar5-compressed.cbr are tiny libarchive BSD-licensed decoder fixtures, with only the entry filename/header CRC changed to use a PNG extension. Their payload is synthetic test data, not an image: use them for decoder integrity checks, not bitmap decoding.
Sources: libarchive/libarchive commit 7219b0134d771dc4b51bf86b4d01761b87398b1b, libarchive/test/test_read_format_rar_compress_normal.rar.uu (only the 20-byte test.txt member retained), and test_read_format_rar5_compressed.rar.uu.
